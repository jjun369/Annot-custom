# PageDock: 20분 읽고 다시 이어 공부하기

## 1. 읽기 전 2분

Library의 `계속 읽기`로 지난 위치를 엽니다. `다시 볼 것`이 있으면 원문을 한 번 확인하고 오늘 읽을 범위를 정하세요. AI 연결은 필요하지 않습니다.

## 2. 읽는 동안 12분

- 핵심 문장은 `중요`, 막힌 문장은 `이해 필요`로 표시합니다.
- `메모`에는 원문의 반복보다 “내가 이해한 뜻 / 아직 모르는 이유”를 적습니다.
- AI 설명은 꼭 필요한 선택 문장에만 요청합니다. 답변이 그럴듯해도 원문을 확인한 뒤 직접 이해 완료로 바꾸세요.
- 나중에 스스로 답해보고 싶은 내용만 복습 카드로 만듭니다. 정의·조건 한 구절은 빈칸 카드도 적합합니다.

## 3. 마무리 5분

현재 PDF의 복습을 엽니다. 답을 보기 전에 머릿속으로 떠올리거나 연습 입력란에 적고, 답과 원문을 확인합니다. 연습 입력은 저장되는 학습 노트가 아니므로 남길 내용은 원문 메모에 적으세요. 단순 카드 이동이나 건너뛰기는 복습 결과가 아닙니다.

입력란 밖에서는 `Space`로 답을 볼 수 있습니다. 답 확인 후 `1`은 다시(내일), `2`는 기억함(3일 뒤)입니다. 버튼에 포커스가 있으면 Space는 그 버튼의 기본 동작을 합니다. 전체 카드 연습도 마지막 카드에서 끝나며, 다시 하려면 새 묶음을 시작합니다.

## 4. 다음 읽기를 위한 1분

막힌 이유를 원문 메모에 남깁니다. 다음에는 `기록 보기`에서 기억나는 단어나 메모를 검색해 정확한 위치로 돌아오세요. 읽던 위치는 기존 이어읽기 기능이 보관합니다.

종류 필터로 중요·개념·외울 것·질문·이해 필요를 고를 수 있습니다. 결과가 많으면 `더 보기`를 눌러 다음 50개를 추가로 표시합니다. 목록의 원문 이동은 그 기록이 가리키는 페이지로 돌아가며, 이해 완료 상태를 자동 변경하지 않습니다.

## 휴대폰과 백업

설정에서 읽을 정리 노트·수집 메모를 골라 휴대폰용 PDF를 만듭니다. [휴대폰 읽기 안내](./MOBILE_READING_KO.md)를 참고하세요. 이 파일은 복구 백업이 아니며, 중요한 시점에는 원본 PDF를 포함하는 수동 전체 ZIP도 보관하세요.

## 꼭 알아둘 제한

- 사이드채팅의 저장된 질문·답변·내 이해는 Library에 보관됩니다. 미저장 웹 답변·질문 초안의 앱 전체 재시작 복구는 보장하지 않습니다. 종료 전 저장하거나 별도로 복사하세요.
- 외부 웹 AI는 사용자가 직접 복사·붙여넣기·전송합니다. 회사 문서 반출 가능 범위를 확인하세요.
- 모바일 오프라인 보관은 휴대폰 뷰어에서 직접 확인해야 합니다.
