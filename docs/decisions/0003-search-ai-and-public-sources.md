# ADR 0003: FTS/Codex first and lawful public sources

Status: Accepted

Version 0.4 uses SQLite FTS5 and optional Codex query/analysis support; embeddings are deferred. Codex uses its official login and automatic model policy. Automated downloads are restricted to lawful public originals after user approval. KIPRIS Plus and EPO OPS credentials are optional and user-specific. Legal status is informational, not an FTO conclusion.
