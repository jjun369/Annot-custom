# PageDock macOS 친구 테스트 안내

Status: Retired historical document.

PageDock은 Windows 10/11 x64 전용으로 운영합니다. 과거 Apple Silicon 테스트판은 지원이 종료되었으며 새로 빌드하거나 친구에게 배포하지 않습니다.

현재 플랫폼 결정은 [ADR 0009: Windows-only desktop support](./decisions/0009-windows-only-platform.md)를 따릅니다. 과거 macOS 실험을 채택했던 이유와 구현 이력은 ADR 0008 및 Git 기록에서만 확인할 수 있습니다.
