# Web AI ideas synthesis (anonymous)

Date: 2026-09-07

Two independent web-AI reviews were requested from an anonymized description of PageDock's current UI and constraints. No repository, screenshot, PDF, account, private conversation, or credential was sent. The responses are product hypotheses, not usability measurements.

| Suggestion | Decision | Reason |
| --- | --- | --- |
| Keep copy/import as the main web-AI path and progressively disclose low-frequency controls | Adopted | Reduces visible control density while preserving exact request recovery and manual sending. |
| Keep provider/request details available but secondary | Adopted | A provider tab does not redefine the immutable request's provider or mode. |
| Add a short “내 이해 / 아직 확인할 점” note after a single answer or comparison | Adopted | Supports the reading loop without writing into PDF history, Knowledge, or highlights. |
| Keep exact source return and the existing resume state | Adopted | Returning to the bounded source is more reliable than creating another study-state system. |
| Remove immutable receipts or use the current web tab to reinterpret an old request | Rejected | Would break request integrity and re-entry safety. |
| Automatically save a conclusion to Knowledge, resolve a highlight, or score a winner | Rejected | Violates explicit user review and provenance boundaries. |
| Automate consumer-web DOM entry, send, answer polling, or cookie access | Rejected | The product contract is deliberate copy/paste and user-controlled web interaction. |
| Add OCR, a minimap, a new resume table, or a new cross-provider API | Deferred/rejected here | Outside this focused Reader-first change and would add new data or provider risk. |
| Treat a fixed `60%` panel height or claimed success/click/cost figures as evidence | Rejected | The real window must be inspected; the supplied figures were not measurements. |

The implemented scope therefore changes presentation and adds an optional sidechat-only reflection while preserving bounded source anchors, request receipts, manual web use, and existing backup compatibility.
