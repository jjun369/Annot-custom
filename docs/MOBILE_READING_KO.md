# 모아둔 지식·메모를 휴대폰에서 읽기

## 두 파일의 역할

| 파일 | 용도 | 담기는 내용 |
| --- | --- | --- |
| `Mobile/PageDock-Mobile.pdf` | 휴대폰에서 읽기 | 직접 선택한 문서의 기록과 정리 노트·수집 메모의 현재 사본 |
| 수동 전체 백업 ZIP | PC 고장·이동 시 복구 | 원본 PDF와 Library 공부 기록, 지식 원문·정리 노트·이력 등 |

모바일 PDF는 백업을 대신하지 않습니다. 자동 백업은 원본 PDF를 제외하고 최근 3개만 유지합니다. 중요한 시점에는 수동 전체 백업도 별도로 보관하세요. 기존 데이터가 있는 Library에 가져올 때 파일 충돌 처리가 있으므로, 새 PC 복구를 확인할 때는 빈 Library를 이용하는 것이 명확합니다. 이 기능이 기존 Knowledge 내용을 자동으로 합쳐 주는 것은 아닙니다.

## 처음 준비하기

1. PageDock **설정 → 휴대폰에서 읽기**를 엽니다.
2. **정리 노트·수집 메모 고르기**에서 원하는 항목을 검색하고 추가합니다. 논문 PDF를 고르지 않고 메모만 넣어도 됩니다. 논문에 남긴 밑줄·메모는 PDF Reader의 더보기에서 그 문서를 모바일 보관함에 추가합니다.
3. Library와 다른 **연결 폴더**를 지정합니다. 이미 사용하는 폴더 동기화 서비스의 폴더나, 직접 파일을 옮길 별도 폴더를 사용할 수 있습니다.
4. **휴대폰용 읽기 PDF 만들기**를 누릅니다.
5. 휴대폰으로 `Mobile/PageDock-Mobile.pdf`를 옮기거나 연결 폴더에서 열어 읽습니다. 오프라인에서 읽으려면 사용 중인 휴대폰 뷰어에 파일을 저장해 두세요.

PageDock이 알려주는 성공은 연결 폴더에 파일을 썼다는 뜻입니다. 클라우드 업로드 완료나 휴대폰 다운로드 완료까지 확인하지는 않습니다. 폴더 설정과 자료 선택만으로 새 서비스에 로그인하거나 자료를 업로드하지 않습니다. 연결 폴더를 기존 동기화 폴더로 고르면 그 서비스가 파일을 전송할 수 있으므로 회사 자료의 반출 범위는 직접 확인하세요.

## 다시 읽을 때

- PC에서 원래 메모를 계속 수정합니다. 모바일 사본의 수정은 PC로 돌아오지 않습니다.
- 변경 후 다시 PDF를 만들면 현재 선택 내용으로 갱신됩니다. 자동 발행은 기본 꺼짐이며, 사용자가 켜야 동작합니다.
- 수집 메모는 정리 완료나 검증된 결론이 아닙니다. PDF에서도 정리 노트와 수집 메모·AI 추론을 구분해 읽으세요.
- 읽기 PDF의 노트 본문은 텍스트 중심입니다. 복잡한 Markdown 표·수식은 원래 Knowledge 화면과 동일하게 조판되지 않을 수 있습니다. 원문 위치 정보는 PC에서 근거를 다시 찾기 위한 참고입니다.
- 사라진 선택 항목은 경고를 확인하고 보관함에서 제거하거나 원본을 확인합니다.
- 외부에서 모바일 PDF가 수정되면 자동 덮어쓰기를 막습니다. 필요할 때 **수정본 보존 후 새로 만들기**를 사용합니다.
- 사이드채팅은 자동으로 포함하지 않습니다. 미선택 자료와 앞으로 새로 만드는 노트도 저절로 추가되지 않습니다.

## 원본을 지키기

**PageDock 복구 백업 → 연결 폴더에 수동 복구 백업**은 원본 PDF를 포함하는 ZIP을 만듭니다. 수동 백업은 자동으로 삭제하지 않습니다. 다른 PC에서는 ZIP을 보관한 다음 빈 Library에서 복구하고 내용을 확인하세요. 로그인 토큰과 PC별 모바일 선택·폴더 설정은 복구 대상이 아니므로 새 기기에서 다시 설정합니다.

휴대폰 실기기의 파일 연결 방식과 오프라인 뷰어 동작은 기기마다 다릅니다. Windows에서 생성·렌더링을 검사한 것을 모든 휴대폰에서 확인한 것으로 해석하지 마세요.
