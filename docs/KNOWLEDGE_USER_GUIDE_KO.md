# PageDock 지식 정리 사용 설명서

PageDock의 지식 정리는 아무렇게나 작성한 기술 메모를 수집하고, ChatGPT OAuth로 연결된 Codex가 위키 변경안을 제안하도록 만든 개인용 기능입니다. AI가 위키를 자동으로 덮어쓰지 않으며, 사용자가 검토하고 승인한 내용만 현재 위키에 반영됩니다.

상단의 `?` 버튼 또는 `F1`을 누르면 현재 화면에 맞는 사용법, 전체 흐름, 문제 해결 팁을 볼 수 있습니다. 도움말은 필요할 때만 열리며 작업을 자동으로 방해하지 않습니다.

## 1. 메모 수집

- `지식 > 수집함`의 입력창에 메모를 붙여넣고 `수집함에 넣기`를 누릅니다.
- `.txt`, `.md`, `.markdown` 파일은 여러 개를 한 번에 끌어놓거나 선택할 수 있습니다.
- 입력 중인 초안은 현재 PC의 앱 저장 공간에 자동 보존됩니다. 수집이 성공해야 초안이 지워집니다.
- 원문은 수집 후 수정하지 않습니다. 같은 내용은 파일명이 달라도 SHA-256으로 한 번만 수집합니다.

### 메모 폴더에서 자동 수집

수집함의 `메모 폴더`에서 Windows 폴더를 연결하면 지식 화면을 열 때와 `새 메모 확인`을 눌렀을 때 하위 폴더의 `.txt`, `.md`, `.markdown` 파일을 확인합니다.

- 20,000자 이하의 새 UTF-8 파일은 AI를 실행하지 않고 바로 수집함에 들어갑니다.
- 원본 파일은 이동·이름 변경·삭제하지 않습니다.
- 같은 내용은 파일명이 달라도 중복으로 수집하지 않습니다.
- 연결한 폴더를 찾지 못해도 이미 수집한 메모는 유지됩니다.
- 큰 파일은 자동 수집하지 않고 분할 미리보기에서 확인합니다.

## 2. ChatGPT OAuth 연결

지식 정리는 API 키를 사용하지 않습니다. 사이드바에서 ChatGPT OAuth 상태를 확인하고 필요하면 `ChatGPT 다시 연결`을 누릅니다.

로그인 상태는 화면을 처음 열 때, 사용자가 상태 확인을 눌렀을 때, 로그인 직후 확인합니다. 주기적으로 확인하지 않습니다. 실제 AI 정리 직전에는 서버가 OAuth 상태를 다시 검증합니다.

네트워크 오류나 AI 응답 오류가 발생해도 PageDock은 자동으로 로그아웃하지 않습니다. `연결 확인 필요`가 표시되면 다음 중 하나를 선택합니다.

- `로그인 상태 확인`: 기존 로그인을 다시 확인합니다.
- `ChatGPT 다시 연결`: 사용자가 직접 OAuth 연결을 다시 진행합니다.
- 나중에 다시 시도: 메모·위키·검색 등 로컬 기능은 계속 사용할 수 있습니다.

API 키 인증이 감지되면 AI 지식 정리만 차단됩니다. 로컬 지식 데이터는 그대로 사용할 수 있습니다.

## 3. AI 정리

- 메모 하나의 `정리`를 누르거나 `다음 10개`를 눌러 순서대로 처리합니다.
- `전체`도 사용할 수 있지만 대기 메모가 20개를 넘으면 확인 창이 표시됩니다.
- 처리는 동시에 여러 개를 실행하지 않습니다. 오류가 나면 다음 메모로 넘어가지 않습니다.
- `현재 작업 후 중지`는 실행 중인 메모까지 끝내고 멈춥니다.
- `즉시 취소`는 현재 Codex 프로세스를 중단하고 원본 메모를 수집함에 남깁니다.
- 앱은 자동으로 AI 작업을 재시도하지 않습니다.

원본이 20,000자를 넘으면 자동으로 AI에 보내지 않고 제목·문단 경계를 이용한 분할 미리보기를 보여줍니다. `제안대로 N개 수집`을 선택하면 조각마다 원본 메모로 보관되고, 100,000자 이하라면 `한 메모로 수집`도 선택할 수 있습니다. 분할은 추가 AI 호출을 사용하지 않습니다. 기존 위키 후보가 문맥 상한 때문에 발췌·생략되면 검토 카드에 경고가 남습니다.

## 4. 변경안 검토

검토 카드는 처음에 제목과 변경 이유만 보여줍니다. `원본과 변경 내용 확인`을 눌렀을 때만 원문과 Diff를 계산하고 표시합니다.

- 초록색: 추가될 줄
- 빨간색: 삭제될 줄
- `Markdown 미리보기`: 반영 후 모습을 확인
- `수정`: AI가 제안한 제목·요약·본문을 직접 고침
- `반영`: 현재 위키에 새 revision 생성
- `보류`: 현재 위키를 변경하지 않음

변경 내용을 펼치기 전에는 실수로 반영할 수 없습니다. 오래된 revision을 기준으로 만든 변경안도 반영할 수 없습니다.

## 5. 위키 직접 수정

위키 문서의 `직접 수정`을 누르면 AI 호출 없이 제목·요약·Markdown 본문을 수정할 수 있습니다. 저장하면 기존 기록을 덮어쓰지 않고 `사용자 직접 수정` revision이 새로 만들어집니다. 변경 메모에는 수정 이유를 선택적으로 남길 수 있습니다.

## 6. Revision 이해와 복원

Revision은 나무위키 문서의 편집 버전과 비슷합니다. 현재가 r5일 때 r2를 복원하면 r2~r5를 지우지 않고 r2 내용으로 새 r6을 만듭니다.

- 수집만 한 메모: revision을 만들지 않음
- AI 변경안 생성: 아직 revision을 만들지 않음
- AI 변경안 승인: 새 revision 생성
- 사용자가 직접 수정: 새 revision 생성
- 충돌함 등록: 현재 본문을 바꾸지 않으므로 revision을 만들지 않음

## 7. Revision 휴지통

현재 revision은 휴지통으로 옮길 수 없습니다. 과거 revision만 선택할 수 있습니다.

1. 위키에서 `Revision 이력`을 펼칩니다.
2. 과거 revision의 `휴지통`을 누릅니다.
3. 휴지통에 있는 revision은 `되돌리기`로 원래 문서의 이력에 복구할 수 있습니다.
4. `영구 삭제`는 확인 후 실행되며 되돌릴 수 없습니다.

휴지통 데이터는 `.annot/knowledge-revision-trash.json`에 별도로 저장됩니다. 따라서 활성 지식 파일에서는 빠지지만 영구 삭제 전까지 복구할 수 있고 휴대용 백업에도 포함됩니다.

## 8. 충돌 처리

AI가 새 메모와 기존 위키가 같은 조건에서 충돌한다고 판단하면 현재 위키를 바꾸지 않고 충돌함에 등록합니다.

- 원본과 충돌 주장을 확인합니다.
- 필요하면 `위키 열기`로 이동해 직접 수정합니다.
- 해결 이유를 `해결 메모`에 남깁니다.
- `메모와 함께 해결` 또는 `관련 없음`으로 닫습니다.

버전·운영체제·환경 차이처럼 둘 다 맞는 경우에는 위키 본문에 적용 조건을 직접 기록한 뒤 해결하는 방식을 권장합니다.

## 9. 저장 위치와 백업

- 활성 지식: `.annot/knowledge-store.json`
- revision 휴지통: `.annot/knowledge-revision-trash.json`
- v1 최초 변환 원본: `.annot/knowledge-store.v1-backup-<hash>.json`

세 파일은 일반 PageDock 휴대용 백업에 포함됩니다. 설정 화면의 전체 ZIP 백업과 일일 자동 백업을 사용할 수 있습니다. 로그인 토큰은 백업에 포함되지 않습니다.

사이드바에는 활성 저장소와 revision 휴지통 크기가 표시됩니다. 파일 크기만으로 경고하지 않으며, JSON 구조가 실제 사용에서 느려질 때 별도 저장 구조를 검토합니다.

## 10. Markdown 내보내기

위키 화면의 `Markdown 내보내기`를 누르면 선택한 폴더 아래에 시간별 `PageDock-Knowledge-...` 폴더가 만들어집니다.

- `INDEX.md`와 현재 revision 기준의 위키 문서만 내보냅니다.
- 각 문서에는 제목·요약·본문과 `topic_id`, `revision`, `updated_at` 정보가 들어갑니다.
- 원본 메모·과거 revision·revision 휴지통은 포함하지 않습니다. 전체 보존이 필요하면 설정의 휴대용 ZIP 백업을 사용합니다.
- 연결된 메모 폴더 안으로는 내보낼 수 없습니다. 내보낸 폴더가 다시 수집되는 일을 막기 위한 동작입니다.

## 11. OpenAI로 전달되는 내용

AI 정리를 실행할 때 선택한 원본 메모와 로컬에서 고른 관련 위키 후보 발췌문이 Codex를 통해 OpenAI 모델로 전달됩니다. 전체 지식 저장소, revision 휴지통, 다른 메모 전체를 자동으로 보내지 않습니다.

## 12. 문제 해결

### 정리 버튼을 사용할 수 없음

`로그인 상태 확인`을 누릅니다. API 키 인증이면 ChatGPT OAuth로 다시 연결해야 합니다.

### AI 정리가 실패함

원본 메모는 사라지지 않습니다. 네트워크·사용량 제한·응답 오류 메시지를 확인하고 사용자가 원할 때만 `다시 정리`를 누릅니다.

### 잘못된 내용을 반영함

Revision 이력에서 이전 내용을 복원합니다. 복원도 새 revision으로 남기 때문에 중간 기록이 사라지지 않습니다.

### Revision을 잘못 휴지통으로 보냄

해당 위키의 `Revision 휴지통`을 열어 `되돌리기`를 누릅니다. 영구 삭제한 revision은 앱에서 복원할 수 없으므로 백업이 필요합니다.

## 13. 지원 운영체제

PageDock은 Windows 10/11 x64 전용입니다. macOS와 Linux 설치 파일은 제공하지 않으며 해당 운영체제의 사용·테스트 절차도 지원하지 않습니다.
